Extracting inspection reports automatically

A supplier sends an inspection report with every delivery, sometimes as a PDF, sometimes as a scan. Today someone in goods receipt types in the values. A pipeline reads the values, compares them with the target values and provides them as an import file for the ERP.

How it works

  1. The inspection report arrives

    By email to a dedicated address or as an upload to a folder. Scans and PDFs are handled the same way.

  2. Text and tables are read

    Text recognition and a language model find the agreed fields, even if every supplier uses a different layout.

  3. Values are checked

    Measured values are compared with the target values from the purchase order or drawing. Missing fields, illegible passages and outliers are flagged.

  4. You only confirm the exceptions

    Unambiguous records go straight to the export. Flagged records are shown side by side with the excerpt from the original.

  5. Export to the ERP

    As a file in the format your ERP can import. The original document stays linked.

What is not automated

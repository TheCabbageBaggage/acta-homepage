Document check

Trial extraction with your own documents. Afterwards you know how reliably the fields are read and how many hours a month this saves.

  • Recommendation for the pilot and a 30-minute online meeting
Not included
production pipeline, connection to the ERP

up to 20 documents, the list of fields you need, and your monthly volume
Next
With the result you decide whether a pilot P1 is worthwhile. There is no obligation to order one.

  • Delivery time 5 working days
  • Payment on order

E1

Server IT security check

A review of the security of one Linux server. We only read data and change nothing on the system.

For whom
Companies with their own or rented Linux servers but no security department of their own
Scope
  • Check script that you run yourself (Lynis and our own checks: open ports, patch level, SSH, firewall, users, backups, logs)
  • automated evaluation and manual review of the results
  • Report with traffic-light rating and prioritised measures
  • 30-minute online meeting to discuss the results
Not included
changes to the system, penetration testing, forensics, Windows servers
Your data
The check script is readable in plain text before you run it. The result file contains configuration and version information, no user data and no passwords.
You provide
written confirmation that you are authorised to have the server checked, running the script, uploading the result file
Next
Hardening at a fixed price of €390 per server, or ongoing support with L3

€290per server, €250 from 3 servers

  • Delivery time 2 working days after upload
  • Payment on order
  • You run the script yourself, we change nothing
